Part I — Platform Fundamentals

1. Multi-Tenant SaaS Model

  • A single shared platform serves an unlimited number of independent organisations (tenants).
  • Each organisation has its own data, branding, integrations, document numbering, file storage, users, and settings. No tenant can see or touch another tenant's data.
  • All organisations use the same UI, same modules, same workflows — only their data, logos, and configurations differ.
  • A tenant's logo and name appear in the sidebar, headers, login screen, and all PDFs.
  • Each organisation can connect its own Zoho Books accounts, Google Drive folders, GSTIN profiles, bank accounts, and AI thresholds.

2. Multi-Division Data Isolation

  • Every organisation can define multiple Divisions (e.g. North, South, Site-A, Site-B, Trading, Contracting). Each division has Name, Code, Description, and an Active toggle.
  • Users belong to one or more divisions, with one marked as their default.
  • Customers, vendors, projects, items, locations, machinery, stock transactions, quotations, invoices, proforma, credit notes, purchase orders, purchase credit notes, RA bills, workspace files, and HRM records are all scoped to a division.
  • Regular users only see records from divisions they are members of. Untagged records remain visible to administrators only.
  • Administrators and SuperAdmin bypass division scoping and see everything in the organisation.
  • New records are automatically stamped with the user's active division.

3. Multi-User & Roles

  • Three role tiers per organisation: Admin, Manager, User (regular). A global SuperAdmin sits above all organisations.
  • Admins manage users, settings, branding, integrations, and have full access to every module.
  • Managers operate day-to-day workflows (create/edit/submit) within the modules and divisions granted to them.
  • Per-user, per-division module grants decide which modules a user can open. Restricted modules — Administrator, Finance, Analytics — can only be granted to admins.
  • Users with prior activity cannot be hard-deleted; only deactivated so audit trails remain intact. Role badges are colour-coded throughout the UI.

4. Module Access Control

  • 10 module tiles on the ERP Home. The SuperAdmin decides which modules each organisation can enable.
  • Within an organisation, admins assign per-division module access to each user.
  • Disabled modules render as locked tiles with a "Not Enabled" badge and a lock icon.
  • Direct URL navigation to a forbidden module shows a clear "Access Not Enabled" screen with Go Back / Back to Home options instead of redirecting silently. The screen distinguishes between module-not-enabled and admin-only reasons.

5. SuperAdmin Platform Controls

  • Single platform-wide SuperAdmin sits outside every organisation and never appears in any organisation's user list.
  • SuperAdmin Dashboard with stat cards: Total Organisations, Active, Pending Approval, Disabled, Total Users, Pending Requests.
  • Organisations list: search and filter by status, enter any organisation in clearly-marked Override Mode, activate/suspend/disable/re-enable.
  • Override Mode banner: an amber pill at top-right shows the organisation being impersonated, with an Exit button.
  • Pending Requests: review every organisation registration request, approve with chosen modules, or reject with an optional reason. Approval/rejection history is preserved.
  • Platform Settings: toggles for "Allow New Organisation Registrations" and "Allow Public Signups".
  • Platform Branding: set the app logo, app name, tagline, description on the login screen, access request message, support contact, and footer text. A live preview renders changes in real time.
  • Per-organisation management: overview stats, members list with role editing/removal, rename organisation, danger-zone delete that wipes all members and the organisation. Global Users screen for cross-organisation user management.

6. Authentication & Onboarding

  • Split-panel sign-in/sign-up screen with branded left panel (logo, app name, tagline, description, access message, support contact, footer) and form panel on the right. All branding fields driven by SuperAdmin settings. Mobile collapses to a single column.
  • Login: email + password with show/hide toggle, inline validation, loading spinner, success and error toasts.
  • Sign Up: name, email, password (min 6), confirm password with match validation.
  • Invite-based join: invite links pre-fill email (locked) and place the user directly into the inviting organisation.
  • Forgot Password / Reset: separate view, password-reset email, "Back to login" button.
  • Pending Organisation screen: shown when a signed-in user has no organisation assignment, with "Register New Organisation" or "Sign Out".
  • Register Organisation flow: name + module checkboxes (Inventory, Sales, HRM, Analytics). After submission shows Pending (amber) or Rejected (with reason and "Submit New Request") states until SuperAdmin acts.

7. Personal Profile

  • Avatar upload (max 5 MB, auto-compressed) with Remove Photo option; initials fallback in primary colour.
  • Read-only email and role; editable full name; password change (min 6 chars, confirm) with spinner.
  • Theme toggle: Light / Dark / System.
  • Quick Actions configurator — pick up to 6 favourite quick-create shortcuts shown on the ERP Home; drag-and-drop to reorder; minimum of 1 enforced; Save and Reset controls.

Part II — Module Catalogue

8. ERP Home & Navigation

  • Sticky header with company logo + name, ⌘K AI Smart Search bar, notification bell, theme toggle, and user-avatar dropdown.
  • User dropdown links: My Profile, System Settings (admins), Platform Control (SuperAdmin), Logout.
  • Quick Create Bar: up to 6 user-configured shortcuts (Create Invoice, New PO, Add Employee, etc.) shown as coloured icon buttons.
  • Module Tile Grid: 3-column responsive cards with module icon, name, short description, hover scale-up, and chevron. Disabled modules show 60% opacity, not-allowed cursor, and "Not Enabled" badge. "Coming Soon" badge on roadmap tiles.
  • Finance tile opens Zoho Books in a new browser tab. Sidebars across modules are collapsible, with a mobile drawer fallback.

9. Sales Module

9.1 Sales Dashboard

KPI summary cards: Total Customers (Direct/Project breakdown), Active Quotations, Pending Invoices, Monthly Revenue. Recent Customers widget (last 5 with type + status). Module readiness widget (Customer Management, Quotations, Invoicing, RA Bills).

9.2 Customers

  • List page with search (name, GSTIN, PAN, project name/ID), filter by customer type, approval status, and "Group By" parameters.
  • Add/Edit dialog: tabbed Direct vs Project. Fields include Display Name (unique nickname), Trade Name, Legal Name, live GSTIN validation (auto-derives PAN + state code), Opening Balance, Payment Terms, separate Billing and Shipping addresses, Sister-Concern company selector, multiple Contact Persons, and a "Create as Lead" toggle.
  • Project customers add Project Name, Project ID (unique), Project Client (end owner), Project Site Address, separate Billing & Registration addresses, and an Opening RA Bill option.
  • Customer Detail page: info sidebar with GSTIN, PAN, sister concern, addresses, inventory location link, contacts, Zoho contact ID/status/last-synced. Locked badge appears once an approved transaction exists; certain fields then become read-only. Tabs: Invoices, Credit Notes, Quotations, Contacts.

9.3 Leads & 9.4 Quotations

  • Dedicated Leads list with type, project info, contact, and Convert button (warns that project leads will auto-create an inventory location).
  • Quotations List: search, filter by Status, Customer, Lead-type. Advanced filters: Date, Min/Max Amount. Lead-sourced quotations show an amber "LEAD" badge.
  • Quotation View: company logo, customer block, status badge, status actions (Mark as Sent, Approve, Reject), Convert to Invoice, Download PDF, Export as Proforma Invoice, and Convert to Proforma Invoice. Rate-only quotations auto-detected and Qty/Amount columns hidden.

9.5 Proforma & 9.6 Direct Invoices

  • Direct Invoices Summary banner: Time Period selector showing Sales, Tax Amount, Total, Invoice Count.
  • Create Invoice dialog: customer picker, company/billing entity, dispatch location, Invoice Date, Due Date (auto-calculated), Payment Terms, PO Number. GST type auto-detected (CGST+SGST vs IGST) from GSTIN state comparison. Drag-and-drop reorderable line items.
  • Invoice View: visual Status Timeline (Draft → Submitted → Customer Accepted → Admin Accepted → Invoiced → Sent → Cancelled). Role-aware transition buttons. Download PDF, Print, Refresh from Zoho, Create Credit Note. Items table groups GST breakdown by rate automatically; TDS section/amount displayed.

9.7 Sales Credit Notes

Summary cards (Total ₹, Draft ₹, Issued ₹). Filters by Status, Company, Customer. Actions include Submit for Approval, Approve, Issue Credit Note, Reverse, Cancel, Delete.

10. Project Management & RA Bills

10.1 Projects List & 10.2 Project Detail Dashboard

  • Mirrors Customers page but filtered to project customers.
  • Analytics tab: Date Range selector. KPI cards for Revenue, Total Cost, Profit (colour-coded), Margin %. Cost Breakdown Pie, P&L Bar Chart. Add Project Expense dialog. Currency auto-scales to Lakhs / Crores.
  • Items tab: project-specific BOQ/contract items. RA Bills tab: filtered RA bills with quick-create.

10.3 Master Items & 10.4 RA Bills List

Org-wide master items with Name, HSN/SAC Code, Tax Rate, Active toggle. RA Bills List includes search, Status filter (Pending grouping, Draft, Submitted, Client Accepted, Admin Accepted, Invoiced, Sent). Opening bills excluded from "Pending" automatically.

10.5 RA Bill View & 10.6 RA Bill Spreadsheet Editor

  • 6-step visual Status Timeline. "Opening Bill" amber badge for baseline bills.
  • Export PDF dialog: Filter Mode (This Bill Only / Complete Bill / Selected Categories), multi-select category list, toggles for Show Hold Column, Hide Previous & Cumulative, Show Groupwise Totals.
  • Version History side panel: last 10 changes with user, timestamp, structured diff (header changes + per-line additions/removals with before→after arrows).
  • Google Sheets integration: toggle embeds the live sheet as a full-height iframe inside the bill view.
  • Attachments organised in stages: MB Slips, Client Bill, Invoice Receiving. Locked once Admin Accepted.
  • Generate Invoice dialog: Line Type (Short / Summary / Detailed), TDS logic, live preview.
  • Spreadsheet Editor: Full in-browser spreadsheet with add/remove rows, drag-to-reorder, collapsible categories, undo/redo, copy/paste. 6-decimal internal precision with carry-forward, hold redistribution, opening-bill mode, and configurable pagination.

11. Purchase Module

  • Dashboard: KPI cards (Total Vendors, This Month Purchases, Total Purchase Value, Pending Approvals).
  • Vendors: search, bulk import CSV, inline add/edit, bank account verification for vendor payouts.
  • Purchase Orders: Status filters, Create PO dialog (vendor, delivery location, PO date, line items), hover-reveal dropdown for row-level views.
  • Purchase Bills (Transactions): Tabs for All / Pending / Sent Back. Advanced Filters panel. Split "New" button (Purchase Entry / Purchase Return / Purchase Rate Reduction). AI Extract button uploads an invoice PDF/image to pull vendor name, GSTIN, invoice number, date, line items, totals with confidence thresholds.
  • Purchase Credit Notes: "New Credit Note" dropdown (Purchase Return or Rate Reduction), row click opens read-only Purchase Bill View. Admin approvals and Re-sync to Zoho.

  • Machinery: Dedicated catalogue for equipment with location-specific availability.

Sentinel handling (-1 for cleared, 0 for explicit zero); debounced calculation. Highlighted Sunday rows for weekly advance entries.
  • Payments: Separate workflows for Regular Monthly and Weekly Advances. Quick Pay rapid-payment interface (UPI/IFSC). Bank-ready bulk upload files in CSV, TXT, XLS with configurable column mapping for multiple banks.
  • Salary Slips: Multilingual (English/Hindi). One-click PDF export rendered from a fixed off-screen 794px HTML canvas for layout fidelity.
  • Masters: Designations, Projects master (linked to inventory customers), Settings (default salary divisor, Google Drive folder isolation).

Part IV — Data Isolation & Security

🛡️
Every record is scoped to the organisation that owns it; no cross-tenant access is possible. Inside an organisation, division scoping further restricts access to records belonging to divisions the user is a member of.
  • Untagged records: Division-less records are visible only to administrators and SuperAdmin. Admins and SuperAdmin inherently bypass all division scoping.
  • Restricted modules: Administrator, Finance, and Analytics modules can only be granted to Admins.
  • Immutability: Profile fields like SuperAdmin status, organisation membership, and active flag cannot be self-modified — only the appropriate authority can change them.
  • Server-side Validation: All sensitive fields and document numbers are write-validated server-side regardless of UI state.
  • Audit Integrity: Audit identity is preserved perfectly even after a user is deactivated.
  • Document Security: Per-organisation storage isolation for sensitive HR documents (photo, Aadhaar, bank proof). Zoho and Google Drive credentials are encrypted per organisation, per company.
